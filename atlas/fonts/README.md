# Embedded faces

does not fall back. Sources:

| `geist-mono-*.woff2` | Geist Mono | SIL OFL 1.1 — [vercel/geist-font](https://github.com/vercel/geist-font) |
| `instrument-serif-*.woff2` | Instrument Serif | SIL OFL 1.1 — [Instrument Serif](https://github.com/instrument/instrument-serif) |

Fetched from the [Fontsource](https://fontsource.org) latin subsets.
